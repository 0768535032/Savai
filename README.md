# Savai

Brand strategy and visual identity site for [Savai Creative](https://savai.co.ke), Nairobi.

This is a Vite + React app. Vercel deploys from `main`.

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

Copy `.env.example` to `.env` and set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` so the contact form can send inquiries.
